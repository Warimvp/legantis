De la maquette à la mise en ligne.

Un devis écrit au départ, des livraisons régulières ensuite, et le code source à la fin.

Les quatre étapes d'un projet d'application web

  1. Étape 01 · devis gratuit

    Cadrage

    Nous décrivons avec vous les utilisateurs (visiteurs, clients, administrateurs), ce que chacun peut faire et les règles propres à votre activité. Vous recevez un devis détaillé, gratuit et sans engagement, avec le prix et le délai.

  2. Étape 02

    Maquettes

    Les écrans sont dessinés pour le téléphone comme pour l'ordinateur, dans les deux langues s'il le faut, et validés avec vous avant le développement.

  3. Étape 03

    Développement

    Des livraisons régulières sur une adresse de test : vous parcourez l'application comme vos utilisateurs le feront, et vous corrigez le cap à chaque étape.

  4. Étape 04

    Mise en ligne et suivi

    Publication de l'application, remise du code source et de la documentation, puis corrections et évolutions dans la durée.

04Questions fréquentes

Application web : vos questions, nos réponses.

Application web, site vitrine, boutique en ligne : quelle différence ?

Un site présente votre activité (c'est l'objet de notre prestation de création de site web). Une boutique en ligne vend : catalogue, panier, commandes. Une application web fait travailler vos utilisateurs : comptes, données, règles, documents. Nous développons les trois ; au cadrage, nous retenons le plus simple de ce qui répond à votre besoin.

Une application web peut-elle remplacer une application mobile ?

Souvent, pour commencer : elle s'ajoute à l'écran d'accueil du téléphone, se charge vite et peut fonctionner hors connexion. Les boutiques d'applications apportent surtout la visibilité dans l'App Store et Google Play et l'accès à certaines fonctions de l'appareil. Nous vous disons au cadrage si une application mobile vaut l'investissement dans votre cas.

Combien coûte une application web ?

Cela dépend de ce qu'elle fait : nombre de pages et de fonctions, types d'utilisateurs, paiement en ligne, espace d'administration, langues, liens avec vos autres outils. Nous vous remettons gratuitement un devis détaillé, avec le prix et le délai, par écrit.

Mon site sera-t-il bien placé sur Google ?

Nous soignons la base technique : pages rapides, titres et descriptions, plan du site, données structurées. Les positions dépendent aussi du contenu et du temps : personne ne peut en promettre une, et nous ne le ferons pas.

Pouvez-vous reprendre un site ou une application existante ?

Oui : audit de l'existant, corrections, modernisation ou refonte. C'est le rôle de notre prestation de conseil et reprise d'existant.

Mon application web peut-elle encaisser des paiements ?

Le mode d'encaissement (paiement à la livraison, virement, carte bancaire en ligne) fait partie des questions du cadrage. Nous vous disons ce qui est faisable pour votre activité, et à quel coût, avant tout engagement de votre part.

Recevrai-je le code source ?

Oui : à la mise en ligne, nous vous remettons le code source et la documentation.

Comment se passe la demande de devis ?

Vous nous écrivez quelques lignes : votre activité, ce que vous voulez développer, les supports visés, le délai souhaité. Nous répondons sous 48 heures ouvrées, par téléphone ou par écrit, pour comprendre le besoin, puis nous remettons un devis détaillé, gratuit et sans engagement, avec le prix et le délai.
