01Types de projets

Quelle application mobile pour votre activité ?

Une application mobile se justifie quand elle apporte ce qu'un site seul donne mal : l'appareil photo, les notifications, une présence dans l'App Store et Google Play. Voici quatre cas types.

  1. Une application pour vos clients

    Prise de rendez-vous, commande, suivi, abonnement, compte personnel, notifications : vos clients vous retrouvent sur leur téléphone, en français comme en arabe.

    • Rendez-vous
    • Commande
    • Notifications
    • Compte client

  2. Une application pour vos équipes

    Suivi de chantier, tournées, relevés, inventaires : l'équipe saisit sur le terrain, photos comprises, même sans réseau, et les saisies se synchronisent au retour de la connexion.

    • Terrain
    • Photos
    • Hors ligne
    • Synchronisation

  3. Votre propre application

    Vous avez une idée à publier sur les boutiques d'applications : nous la cadrons, la dessinons, la développons et la mettons en ligne, comme nous l'avons fait pour Rihla.

    • Cadrage
    • Maquettes
    • Publication

  4. Le prolongement d'un service existant

    Vous avez déjà un site ou une plateforme : l'application mobile le prolonge sur le téléphone, avec les mêmes comptes et les mêmes données, dans la mesure où votre système permet de les relier.

02Méthode

De l'idée à l'App Store.

Quatre étapes, avec un devis écrit au départ et une application prête pour l'App Store et Google Play à l'arrivée.

Les quatre étapes d'un projet d'application mobile

  1. Étape 01 · devis gratuit

    Cadrage

    Nous listons avec vous les écrans, les fonctions, les plateformes visées (iPhone, Android ou les deux) et ce qui doit marcher sans réseau. Vous recevez un devis détaillé, gratuit et sans engagement, avec le prix et le délai.

  2. Étape 02

    Maquettes

    Chaque écran est dessiné et validé avec vous avant la première ligne de code, dans les deux langues s'il le faut : vous voyez l'application avant qu'elle existe.

  3. Étape 03

    Développement et essais

    Des versions de test s'installent sur votre téléphone à chaque étape. Vous essayez, vous corrigez le cap, et vous gardez la main sur l'avancement.

  4. Étape 04

    Publication et suivi

    Nous préparons et soumettons l'application à l'App Store et à Google Play (fiches, captures d'écran, politique de confidentialité), puis nous remettons le code source et la documentation. Corrections et évolutions suivent dans la durée.

04Questions fréquentes

Application mobile : vos questions, nos réponses.

Faut-il une application pour iPhone et une autre pour Android ?

Pas deux projets séparés : nous développons à partir d'une seule base de code, ce qui donne une application iPhone et une application Android aux mêmes fonctions, qui évoluent ensemble. Si un besoin précis demandait autre chose, nous vous le dirions dès le cadrage.

Combien coûte une application mobile ?

Cela dépend de ce qu'elle fait : nombre d'écrans, comptes utilisateurs, notifications, paiement, mode hors connexion, espace d'administration, langues. Nous ne publions pas de prix unique, car deux applications ne se ressemblent pas : nous vous remettons gratuitement un devis détaillé, avec le prix et le délai, par écrit.

Combien de temps faut-il pour la publier ?

Le délai figure dans le devis, une fois les écrans et les fonctions listés. À la fin du développement, la revue par Apple et par Google ajoute une étape que personne ne maîtrise : nous la prévoyons dans le calendrier.

Pouvez-vous publier l'application sur l'App Store et Google Play ?

Oui, nous prenons en charge les exigences des deux boutiques : fiche de l'application, captures d'écran, politique de confidentialité, déclaration des données collectées et, quand l'application permet de créer un compte, suppression du compte depuis l'application. Apple et Google demandent chacun un compte développeur payant.

L'application fonctionnera-t-elle sans Internet ?

Elle le peut, si on la conçoit ainsi : les données utiles sont gardées sur le téléphone, les saisies sont enregistrées, puis synchronisées au retour du réseau. Nous décidons avec vous, au cadrage, de ce qui doit marcher hors connexion.

L'application sera-t-elle disponible en arabe ?

Oui : interface en français, en arabe ou dans les deux langues, avec le sens de lecture de droite à gauche géré dès la maquette. L'anglais s'ajoute si votre public le demande.

Recevrai-je le code source ?

Oui : à la mise en ligne, nous vous remettons le code source et la documentation.

Comment se passe la demande de devis ?

Vous nous écrivez quelques lignes : votre activité, ce que vous voulez développer, les supports visés, le délai souhaité. Nous répondons sous 48 heures ouvrées, par téléphone ou par écrit, pour comprendre le besoin, puis nous remettons un devis détaillé, gratuit et sans engagement, avec le prix et le délai.
